# Bulk acronym/terminology library. Plain-text on purpose (per explicit
# request) so it's fast to scan and extend without JSON ceremony -- this is
# the "quick coverage expansion" layer; the richer per-term JSON files
# (sources, synonyms, JD-sweep Level C citations) stay the primary format
# for terms that warrant that depth.
#
# Format (pipe-delimited, one term per line):
#   category_key|ACRONYM|Full Expansion
# category_key must match a key in keywords/*.json (aerospace_defense,
# program_management, manufacturing_quality,
# systems_engineering_certification, government_contracting, tools_systems).
# Lines starting with # are comments. Blank lines ignored.
# All entries here are Level E (internal domain-knowledge compilation, not
# yet backed by a fetched citation) unless later cross-confirmed by a real
# job-posting sweep the way app/knowledge_base/job_descriptions/ does for
# the JSON-defined terms.
